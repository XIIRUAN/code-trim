# Coding Agent Lean Review

中文 | [English](README.en.md)

面向 Coding Agent 的轻量代码精简 Skill：代码生成或修改后，快速检查重复防御和缺乏当前需求的抽象；只有必要时才进行局部消融验证。

**快速精简 + 按需消融。** 保留真实需求和必要保障，不以删除行数为目标。

## 适用场景

- 完成功能或修复后，检查本次改动是否引入重复校验、兜底或重试。
- 精简没有当前用途的工厂、包装层、兼容分支和扩展点。
- 对一个明显增加复杂度、但难以直接判断必要性的防御单元做局部验证。

## 工作方式

```text
本次新增或修改的代码
  → 一轮快速检查
  → 根据契约、调用路径或等价实现判断
  → 有证据则精简；证据不足则保留
  → 必要时最多一次局部消融实验
  → 纳入任务正常验证，简短收尾
```

“消融”指在隔离的本地变体中临时移除或简化一个单元，再运行覆盖其保护行为的最小相关检查。实验失败或结论不明确时恢复原状；测试通过本身不证明代码冗余。

## 范围与边界

| 项目 | 默认行为 |
| --- | --- |
| 读取范围 | 本次改动；仅为解决具体问题读取直接依赖 |
| 审查预算 | 一轮快速检查，无明确候选即停止 |
| 消融预算 | 每个任务最多一次；用户要求深入审查或正确性需要时才扩展 |
| 验证 | 复用已有结果；仅针对未解决的回归风险增加检查；遵守仓库必需检查 |
| 输出 | 在正常任务回复中简述有意义的精简和验证，不另写审查报告 |

默认保留认证、授权、数据完整性、并发、幂等和资源清理保障。外部输入验证应与真实边界风险相称；类型标注不等于运行时校验。多个删除组合后，每项必要保证仍须至少保留一个有效保护层。

## 安装

下载本仓库，将含有 `SKILL.md` 的目录命名为 `coding-agent-lean-review`，放到宿主 Agent 的技能发现目录。

例如，使用 `~/.agents/skills/` 的宿主对应目录如下：

```text
~/.agents/skills/coding-agent-lean-review/SKILL.md
```

具体发现目录和重新加载方式以所用宿主的说明为准。此仓库仅包含 Markdown 指令和说明，无需安装运行时依赖。

## 使用示例

```text
使用 $coding-agent-lean-review，快速检查本次代码改动。
保留必要行为与错误契约；没有明确精简候选就停止。
```

```text
完成修复后，使用 $coding-agent-lean-review 做一轮精简。
只在必要时对一个复杂防御单元做局部消融，并纳入正常验证。
```

宿主可依据 Skill 描述选择加载；安装本身不保证每次代码修改后自动执行。需要明确调用时使用上述提示，并遵循宿主支持的调用语法。
